# 개인정보 보호

프로세스를 시작하거나 데몬에 연결하기 전에 지시를 검사한다.
보수적인 검사기는 이메일 형태의 문자열, 알려진 토큰 접두사, bearer 인증 정보,
흔한 인증·계정 필드 대입을 거절한다.
원본 경로, 저장할 argv(인자 배열), 보존할 모든 JSON도 검사한다.
이 휴리스틱은 모든 비밀 정보를 찾아내는 탐지기가 아니다.
전송 전에 지시 파일과 그대로 전달할 옵션을 검토해야 한다. 인증 정보를 명령행 인자로 넘기지 않는다.

각 엔진은 자체 정책에 따라 원본 이력을 보관한다.
Codex의 경우 제품은 크기가 제한된 스냅샷을 일시적으로 읽는다. 세션·계정 메타데이터는 절대 복사하지 않는다.
필요하고 안전한 작업 시작·정확한 입력·종료·최종 출력 줄만 복사한다.
불필요하거나 민감한 줄은 원래 범위, 해시, 역할 라벨, 생략 사유만 남긴다.
필수 줄이 민감하면 그 줄에 의존하는 사실은 unknown(알 수 없음)으로 남는다.
디코딩한 JSON도 검사한다. 유니코드 이스케이프로 알려진 민감 패턴을 숨길 수 없다.
첫 턴에 주입된 맥락은 복사하지 않는다.
receipt 번들은 허용 목록으로 제한한 스트림 제어 필드와 분류한 오류를 보존한다.
0.1.1부터는 `item.completed`(항목 완료 이벤트)의 에이전트 메시지 후보 텍스트도 같은 개인정보 검사를 통과한 뒤에만 해시 요약값과 함께 보존한다.
원시 이벤트를 감싼 전체 구조는 절대 저장하지 않는다. 민감한 후보는 생략 사유만 남긴다.
4 MiB를 넘는 스트림 줄은 줄바꿈까지 버린다. 최종 응답의 근거로 쓸 수 없다.
원본 JSONL 줄에는 32 MiB 스냅샷 상한 안에서 별도 크기 제한이 없다.
진단 설명은 고정된 안전한 텍스트다. 유용한 경우 개수·오프셋을 포함한다.
원본 예외 문자열이나 거절한 내용은 포함하지 않는다.
reported(보고됨) 출력은 observed(관측됨) 출력과 같은 비공개 파일 권한을 쓴다.

`run --child-stderr PATH`를 지정하면 Codex·Claude·agy 대상 자식의 stderr 바이트를
개인정보 필터링 없이 그대로 저장소 밖의 호출자 관리 파일에 쓴다.
증거가 아니며 계정 정보 등이 들어 있을 수 있으니 호출자 책임으로 관리한다.
파일 내용과 경로는 receipt나 저장소에 기록하지 않는다.

파일은 0600으로 생성한다. 기존 파일은 덮어쓰고 권한을 0600으로 설정한다.
부모 디렉터리는 미리 존재하고 쓸 수 있어야 한다. 목적지를 사용할 수 없으면 전송 전에
종료 코드 2로 거절하고 attempt를 만들지 않는다. 옵션을 생략한 경우와 `agy --version` 같은
보조 프로세스의 stderr는 DEVNULL로 버린다. 이 옵션은 `run --via exec` 전용이다.

Claude Code 2.1.310 원본 기록에는 attachment와 api-request-blob 행 안에 계정·조직·환경 정보가 들어 있었다.
이 행들은 다른 API·맥락 메타데이터와 함께 원본 줄 보존 대상에서 제외한다.
Claude 프로필은 알려진 조직·인증 필드 대입도 저장 전에 거절한다.
정확히 일치하는 입력 user(사용자 메시지)와 안전하게 연결된 assistant(어시스턴트 메시지)·중단 줄만 원본 바이트 보존 대상이 될 수 있다.
줄 전체를 원시 텍스트와 디코딩한 JSON 양쪽으로 검사한다.
거절한 줄은 생략한다. 내용을 가린 뒤 원본이라고 부르지 않는다.
도구 결과 user는 별도의 지시 입력이 아니다.

필요한 부모 연결 사슬이 생략된 attachment나 도구 결과 행을 지날 수 있다.
별도로 표시한 **파생 연결 정보**에는 uuid·parentUuid 필드값과 원본 줄의 바이트 범위·SHA-256만 저장한다.
생략한 행의 유형, 첨부 내용, 계정 필드, 환경은 절대 저장하지 않는다.
다른 실제 입력 user를 연결을 잇는 파생 정보로 만들지 않는다.
보존한 바이트와 파생 정보로 오프라인 연결 검사를 할 수 있다.
해시만으로 생략된 원본을 재구성하거나 진위를 확인할 수는 없다.
이 식별자도 연결 관계를 드러내므로 비공개 로컬 데이터다.

Claude 스트림에서는 선별한 init/result 필드와 개인정보 검사를 통과한 성공 결과 텍스트만 보존한다.
subtype, 원시 이벤트를 감싼 전체 구조, 계정·조직 메타데이터는 보존하지 않는다.
원본 실행 파일은 여전히 자체 이력에 민감한 데이터를 쓸 수 있다.
receipt를 필터링해도 그 이력은 바뀌지 않으며 민감 정보도 제거되지 않는다.

해시와 타임스탬프만으로도 내용의 동일 여부와 시점이 드러날 수 있다.
지시 내용, 경로, 스레드·턴 식별자, 모델 인자, 안전한 최종 응답은 비공개 로컬 데이터다.
디렉터리 권한은 0700, 파일 권한은 0600이다.
저장소 경로와 Codex/Claude 원본 포착 경로의 심볼릭 링크는 거절한다.
이는 같은 OS 사용자, root, 침해된 도구, 백업, 파일시스템 스냅샷으로부터 데이터를 보호하지 못한다.
데이터와 해시를 함께 바꿀 수 있는 공격자에게서도 보호하지 못한다.
원본 실행 파일과 선택적 Rust 브리지는 신뢰하는 로컬 프로그램이다. 샌드박스에 가둔 적대적 프로그램으로 취급하지 않는다.

`forget`은 게시된 번들 하나와 저장된 모든 체크포인트를 삭제한다. 번들이 손상되어 있어도 삭제한다.
초기화 프로세스가 강제 종료되어 남은 숨김 `.pending-*` 디렉터리는 아직 게시되지 않은 비공개 의도 기록이다.
이 잔여물은 실행 중인 초기화 프로세스가 없을 때만 삭제한다.
이는 안전한 완전 삭제가 아니다. 엔진의 원본 로그, 지시 파일, 응답 파일, 자식 stderr 파일, 내보낸 자료, 백업에는 손대지 않는다.
필요하면 각각 따로 삭제한다. 증거를 삭제하면 이후 중복·매핑 조회가 답할 수 있는 범위가 좁아진다.
JSONL·Polylogue 내보내기에는 지시 텍스트와 common E(공통 증거)가 들어 있다.
원본 저장소와 똑같이 주의해서 다룬다.
어댑터는 빠진 receipt 개념을 `common-E.jsonl`로 제공한다.

네트워크 서비스, 계정 인계, 계정 간 조회, 자동 재전송은 제공하지 않는다.
CLI는 요청한 Codex·Claude·Antigravity 원본 실행 파일을 실행한다. 그 실행 파일은 설정된 네트워크 인증 정보를 사용할 수 있다.
래퍼는 인증 저장소를 읽거나 계정 신원을 출력하지 않는다.
일반 inspect/dup/which/list/verify/export 명령은 로컬 번들에만 접근한다.
원본을 다시 읽으려면 포착을 수행하거나 recover를 명시적으로 실행해야 한다.

## 0.3.0의 실험적 Antigravity

[Antigravity 해석](agy.md)은 stream-NDJSON exec/new/resume과 선별 SQLite protobuf 필드를 추가한다.
native 해석은 verified 1.5.9 범위이며 버전·해시 불일치는 경고와 native 사실의 unknown 강등으로 처리한다.
입력 확인에는 이 자식 stream의 유일한 user-input index도 필요하다. 전체 상태와 최종 출력은 단일 유효 result의
reported 사실이다. 시작·완료 시각·모델 활용은 unknown이다. native 취소 흔적은 completed 보고를 무효화할 수 있다.
운영자가 2026-11-15에 기록한 native 실측은 [검증 기록](validation.md)에 있다.
